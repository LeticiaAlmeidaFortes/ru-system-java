# ru-system-java
Sistema de gestão para Restaurante Universitário desenvolvido em Java, com funcionalidades de cadastro de usuários, controle de saldo e consulta de cardápio.

Funcionalidades:
- Cadastro de Estudantes.
- Depósito do saldo, ou visualização.
- Aquisição de plano para as vale refeições, como principais sendo: mensal e anual. Havendo também a opção de plano semanal ou diário para professores ou alunos.
- Consulta de cardápio do dia.

Tecnologias Utilizadas:
- Linguagem: Java com interface gráfica.
- Banco de dados: MySQL.

Como executar:
1. Clone o código do Java.
2. Abra o projeto na sua IDE de preferência.
3. Execute a classe principal 'Login.Java'.
